# Projeto-Pessoal-
# 💊 Cronograma de Medicamentos

## 📋 Sobre o projeto

O **Cronograma de Medicamentos** é um projeto desenvolvido em **JavaScript puro** com o objetivo de organizar horários de doses de medicamentos de forma simples e automática.

O sistema recebe informações como nome da pessoa, medicamentos, horário inicial, intervalo entre as doses e quantidade de doses. A partir desses dados, o programa calcula os próximos horários automaticamente.

## ⚙️ Exemplo utilizado

Neste projeto, foram utilizados:

* 👤 **Nome:** Marcos Soares
* 💊 **Medicamento 1:** Losartana
* 💊 **Medicamento 2:** Amoxicilina
* 🕐 **Horário inicial:** 07:00
* ⏱️ **Intervalo:** 6 horas
* 💊 **Quantidade de doses:** 2

### 📅 Resultado

| Dose    | Horário |
| ------- | ------- |
| 1ª dose | 07:00   |
| 2ª dose | 13:00   |

## 🧠 Conceitos utilizados

Durante o desenvolvimento foram utilizados conceitos básicos de JavaScript, como:

* `const` e `let`
* Variáveis
* Estruturas condicionais `if/else`
* Funções
* Cálculos de horários
* Template literals
* `module.exports`
* Testes automatizados com **Jest**

## 🧪 Testes

O projeto possui testes automatizados para verificar se:

* Os dados dos medicamentos estão corretos;
* O horário inicial está correto;
* O intervalo foi definido corretamente;
* Os horários das doses foram calculados corretamente;
* O status do cronograma está correto;
* O resumo contém as informações esperadas.

## 🎯 Objetivo

O objetivo principal do projeto é colocar em prática os conhecimentos de **lógica de programação e JavaScript**, criando um sistema simples e funcional para organização de horários.

> ⚠️ **Aviso:** este projeto é uma simulação para fins educacionais. Horários e intervalos de medicamentos reais devem seguir a prescrição e a orientação de um profissional de saúde.
